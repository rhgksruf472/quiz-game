# 🎯 나만의 퀴즈 게임 (영화 편)

터미널에서 즐기는 파이썬 퀴즈 게임입니다. 퀴즈를 풀고, 직접 추가하고, 최고 점수를 기록합니다. 프로그램을 종료하고 다시 실행해도 추가한 퀴즈와 최고 점수가 `state.json`에 남아 유지됩니다.

| 항목 | 내용 |
|---|---|
| 주제 | 영화 (기본 퀴즈 5개 제공) |
| 실행 환경 | Python 3.10 이상, 외부 라이브러리 없음 (표준 라이브러리 `json`, `os`만 사용) |
| 실행 방법 | `python main.py` |
| 코드 구조 | 클래스 2개 — `Quiz`(퀴즈 한 문제), `QuizGame`(게임 전체) |
| 데이터 파일 | 프로젝트 루트의 `state.json` (UTF-8, 실행 중 자동 생성) |

## 1. 프로젝트 개요
메뉴에서 번호를 고르면 퀴즈 풀기, 퀴즈 추가, 퀴즈 목록, 점수 확인, 종료 화면이 차례로 나옵니다. 코드는 역할별로 나누었습니다.
- **`Quiz` 클래스**: 문제 한 개(문제 글, 선택지 4개, 정답 번호)를 표현하고, 출력과 정답 확인을 맡습니다.
- **`QuizGame` 클래스**: 퀴즈 목록과 최고 점수를 관리하고, 메뉴 표시·퀴즈 풀기·추가·목록·점수 확인·파일 저장/불러오기를 맡습니다.
- **입력 처리 함수** (`read_int`, `read_text`): 잘못된 입력을 걸러 다시 입력받는 흐름을 한곳에서 담당합니다.

## 2. 퀴즈 주제와 선정 이유
**주제: 영화**

영화 퀴즈는 대중적인 퀴즈이기 때문에 선택했습니다. 누구나 한두 편쯤은 본 영화를 소재로 하면 별도 배경지식 없이 바로 풀어 볼 수 있습니다. 기본 퀴즈는 해외 영화(타이타닉, 해리 포터, 반지의 제왕), 애니메이션(겨울왕국), 한국 영화(봉준호 감독 작품)에서 골랐습니다.

## 3. 실행 방법
```bash
# 1) 저장소 내려받기
git clone https://github.com/rhgksruf472/quiz-game.git
cd quiz-game

# 2) Python 버전 확인 (3.10 이상)
python --version

# 3) 실행
python main.py
```
- 메뉴에서 `1`부터 `5`까지 번호를 입력합니다.
- 언제든 `Ctrl+C`로 중단해도 안내 메시지를 보여 주고 저장한 뒤 안전하게 종료합니다.

## 4. 기능 목록
| 메뉴 | 기능 | 설명 |
|---|---|---|
| 1 | 퀴즈 풀기 | 저장된 퀴즈를 차례로 출제하고 정답/오답을 알려 줍니다. 모두 풀면 `맞힌 개수 × 100 ÷ 전체 문제 수`로 100점 만점 점수를 계산해 최고 점수와 비교·갱신합니다. 퀴즈가 없으면 안내 문구를 보여 줍니다. |
| 2 | 퀴즈 추가 | 문제, 선택지 4개, 정답 번호(1-4)를 입력받아 퀴즈를 등록하고 바로 파일에 저장합니다. |
| 3 | 퀴즈 목록 | 등록된 퀴즈의 문제를 번호와 함께 보여 줍니다. 퀴즈가 없으면 안내 문구를 보여 줍니다. |
| 4 | 점수 확인 | 지금까지의 최고 점수를 보여 줍니다. 아직 풀지 않았으면 안내 문구를 보여 줍니다. |
| 5 | 종료 | 저장 후 프로그램을 종료합니다. |

## 5. 파일 구조
```
quiz-game/
├── main.py        # 프로그램 전체 코드 (Quiz, QuizGame, 입력 처리 함수)
├── README.md      # 이 문서
├── .gitignore     # Git이 추적하지 않을 파일 목록
└── state.json     # (실행하면 자동 생성, Git에는 올리지 않음) 퀴즈와 최고 점수
```

## 6. 데이터 파일 설명 (state.json)
| 항목 | 내용 |
|---|---|
| 경로 | 프로젝트 루트 (`main.py`와 같은 폴더)의 `state.json` |
| 인코딩 | UTF-8 (`ensure_ascii=False`로 한글을 그대로 저장) |
| 역할 | 프로그램을 꺼도 추가한 퀴즈와 최고 점수가 남도록 보관 |
| 저장 시점 | 퀴즈 추가 직후, 최고 점수 갱신 직후, 종료할 때, `Ctrl+C`·입력 끊김으로 중단될 때 |
| 불러오는 시점 | 프로그램 시작 시 |

**스키마**

| 키 | 타입 | 설명 |
|---|---|---|
| `quizzes` | 리스트 | 퀴즈 목록. 각 원소는 아래 세 키를 가진 딕셔너리 |
| `quizzes[].question` | 문자열 | 문제 글 (비어 있으면 안 됨) |
| `quizzes[].choices` | 문자열 4개짜리 리스트 | 선택지 (정확히 4개) |
| `quizzes[].answer` | 정수 1-4 | 정답 번호 (1번부터 시작) |
| `best_score` | 정수 0-100 또는 `null` | 최고 점수. 아직 풀지 않았으면 `null` |

**예시**
```json
{
    "quizzes": [
        {
            "question": "영화 '해리 포터' 시리즈에서 해리가 다니는 마법 학교의 이름은?",
            "choices": ["호그와트", "보바통", "덤스트랭", "일버모니"],
            "answer": 1
        }
    ],
    "best_score": 80
}
```

**파일이 없거나 손상된 경우**
| 상황 | 동작 |
|---|---|
| 첫 실행 (파일 없음) | 기본 퀴즈 5개로 시작합니다. |
| JSON 형식이 깨졌거나, 필요한 키가 없거나, 선택지가 4개가 아니거나, 정답이 1-4가 아님 | `⚠️ 저장 파일이 손상되어 기본 데이터로 복구합니다.`를 출력하고 기본 퀴즈로 되돌린 뒤 파일을 새로 씁니다. |
| 파일을 읽거나 쓸 수 없음 | 안내 문구를 출력하고, 프로그램은 계속 실행됩니다(이번 변경만 파일에 남지 않음). |

## 7. 입력·예외 처리
숫자를 입력받는 모든 곳(메뉴 선택, 정답 입력, 정답 번호 입력)은 `read_int` 함수 하나로 처리합니다.

| 입력 | 처리 |
|---|---|
| 앞뒤 공백 (예: ` 1 `) | 공백을 지우고 정상 처리 |
| 숫자가 아님 (예: `abc`) | `숫자가 아닙니다` 안내 후 다시 입력 |
| 범위 밖 (예: 메뉴 `9`, 정답 `0`) | `범위를 벗어났습니다` 안내 후 다시 입력 |
| 빈 입력 (그냥 Enter) | `아무것도 입력하지 않았습니다` 안내 후 다시 입력 |
| `Ctrl+C` 또는 입력 스트림 종료(EOF) | 안내 메시지를 보여 주고 저장한 뒤 정상 종료 |

문제 글과 선택지(글자 입력)는 `read_text` 함수가 빈 입력을 막고 다시 묻습니다.

## 8. 코드 구조
**`Quiz`** (퀴즈 한 문제)

| 메서드 | 역할 |
|---|---|
| `__init__(question, choices, answer)` | 문제·선택지·정답을 속성으로 저장 |
| `display()` | 문제와 번호 붙은 선택지를 출력 |
| `is_correct(user_answer)` | 고른 번호가 정답인지 `True`/`False`로 반환 |
| `to_dict()` | 파일에 쓸 수 있는 딕셔너리로 변환 |
| `from_dict(data)` | 딕셔너리를 `Quiz`로 복원 (값이 이상하면 `ValueError`) |

**`QuizGame`** (게임 전체)

| 구분 | 이름 | 역할 |
|---|---|---|
| 속성 | `quizzes` | 퀴즈 목록 |
| 속성 | `best_score` | 최고 점수 (없으면 `None`) |
| 메서드 | `show_menu()` | 메뉴 출력 |
| 메서드 | `play()` | 퀴즈 풀기, 점수 계산, 최고 점수 갱신 |
| 메서드 | `add()` | 퀴즈 추가 |
| 메서드 | `show_list()` | 퀴즈 목록 출력 |
| 메서드 | `show_score()` | 최고 점수 출력 |
| 메서드 | `load()` / `save()` | `state.json` 불러오기 / 저장 |
| 메서드 | `run()` | 메뉴 반복 실행, `Ctrl+C`·EOF 처리 |

## 9. Git 작업 방식
- 기능 단위로 커밋하고, 커밋 메시지에 작업 내용을 드러내는 접두사를 붙였습니다: `Feat:`(기능), `Fix:`(수정), `Refactor:`(구조 정리), `Docs:`(문서), `Chore:`(설정).
- 퀴즈 풀기 기능은 `feature/play-quiz` 브랜치에서 작업한 뒤 `main`에 병합(`git merge --no-ff`)해서 브랜치 이력이 남도록 했습니다.
- 이력 확인: `git log --oneline --graph`
- 개발 완료 후 별도 폴더에 저장소를 `git clone`하고, 복제본에서 수정·push한 내용을 원래 작업 폴더에서 `git pull`로 가져오는 실습을 했습니다.
